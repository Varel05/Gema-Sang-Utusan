# Sistem Kekuatan: Kontras Api Kosmis

> **Status:** Kanon Absolut  
> **Tipe:** Prinsip Simbolisme & Polaritas Energi Semesta

---

## 1. Dua Kutub Energi Semesta
Di semesta *Gema Sang Utusan*, energi metafisika termanifestasikan ke dalam polaritas visual dua nyala api yang berlawanan secara diametral:

| Atribut              | Api Putih-Biru ([[jantung_aethel\|Jantung Aethel]])            | Api Ungu Gelap ([[the_husks\|The Husks]])                        |
| :------------------- | :------------------------------------------------------------- | :--------------------------------------------------------------- |
| **Sumber Entitas**   | [[jantung_aethel\|Jantung Aethel]] / Raga [[azariel\|Azariel]] | Rongga tubuh [[the_husks\|The Husks]] / [[corrosion\|Corrosion]] |
| **Hakikat Simbolik** | *Cahaya yang Mengingat*                                        | *Kekosongan yang Terbakar karena Lupa*                           |
| **Sifat Termal**     | Hawa hangat kehidupan, meneduhkan, menyelaraskan               | Hawa dingin beku menusuk tulang, mematikan vegetasi              |
| **Gerak & Bentuk**   | Nyala tatanan anggun, berpusar teratur                         | Berkobar liar, menganga di rongga tanpa kepala/organ             |
| **Motivasi Kosmis**  | Merespons doa tulus, melindungi, memulihkan hukum              | Digerakkan oleh rasa lapar eksistensial, melahap memori          |

---

## 2. Resonansi Sensorik & Polarisasi Deteksi
- **Sengatan Dingin pada Azariel:** Karena kedua energi ini bertolak belakang, Azariel dapat mendeteksi kedatangan The Husks dari kejauhan melalui sensasi "tusukan hawa dingin" yang membakar kontras dengan bara hangat di rongga dadanya.
- **Deteksi Hayati Rimba:** Pohon-pohon purba di perbatasan (seperti akar pinus atau pohon ara) merespons api ungu gelap The Husks sebagai getaran racun dingin di bawah tanah, mengeringkan dedaunan di sekitarnya.
- **Daya Tarik Mangsa:** The Husks terobsesi secara buta mengejar pendar api putih-biru Jantung Aethel semata-mata karena dorongan putus asa untuk mengisi rongga kehampaan di dalam cangkang mereka.
